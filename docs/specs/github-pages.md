# Treasure Quiz — Separate GitHub Pages Site

Treasure Quiz must live in its own public GitHub repository and deploy as a
separate GitHub Pages site at `https://boss-kung.github.io/treasure-quiz/`.

The app continues to use the existing Supabase project
`lfvwdeqfyscalfucfhlp`. Host and player actions remain protected by the
server-side PIN flow already implemented in Supabase.

The deployed site must support two mobile entry points without requiring a
server-side rewrite rule:

- `https://boss-kung.github.io/treasure-quiz/#/host`
- `https://boss-kung.github.io/treasure-quiz/#/play`

The existing private ChatGPT Sites deployment is out of scope and must not be
modified.
